## Описание работы
Реализация основных абстрактных структур данных и алгоритмов в рамках Лабораторной работы №2. Все структуры основаны на базовых классах из Лабораторной работы №1.

## Реализованные задания

1. **Задание 1: Стек (Скобки).** Удаление минимального количества скобок для получения корректной строки.
2. **Задание 2: АТД Множество.** Реализация множества на основе хеш-таблицы с операциями `ADD`, `DEL`, `AT`.
3. **Задание 3: Множество (Пересечения).** Реализация алгоритма, который должен разбить множество натуральных чисел на непересекающиеся подмножества, с минимальной разницей между суммами.
4. **Задание 4: Массив.** Поиск подмассива с заданной суммой.
5. **Задание 5: Двоичное дерево.** Реализация алгоритма Хаффмана для сжатия строк.
6. **Задание 6.1: Хеш-таблица.** Реализация двух видов хеш-таблиц (цепочки и кукушка) и их эмпирический анализ.
7. **Задание 6.2: Реструктуризация.** Динамическая хеш-таблица с увеличением размера при 90% заполнении.
8. **Задание 7: LFU-кэш.** Кэш с вытеснением элементов, к которым реже всего обращались.
